#  Study Reminder (学习提醒助手)

一个基于 Python 3 + Tkinter 开发的本地化桌面学习与进度管理工具，专为重度备考（如考研 408）、期末复习打造。

**纯 Python 标准库实现，无任何第三方依赖，单文件极简部署**。

##  核心特性

- ** 课表解析**：支持按 `周几|课程|时间` 快速录入，并支持“星期X”自动兼容。
- ** 进度追踪**：期末与考研双看板，支持科目增删改查、进度条动态渲染、`+1/-1` 快捷打卡。
- ** 每日复盘**：内置多行文本日记，按日期归档，支持左右切换查看。
- ** 强提醒弹窗**：支持设定多个提醒时间。到点自动弹出全局置顶看板，汇总今日课表、复习进度与日记输入。
- ** 工业级容错机制**（重点）：
  - **防抖自动保存**：停止输入 1 秒后自动落盘，无惧断电死机。
  - **休眠补偿机制**：电脑锁屏/休眠唤醒后，自动检查是否错过提醒，如果错过立刻补弹。
  - **防误触置顶**：弹窗禁用右上角 `X` 关闭，且每次轮询强制拉到屏幕最前。
